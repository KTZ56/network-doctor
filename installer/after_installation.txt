## Recommended First Steps

1. Open Network Doctor.
2. Check the detected network interface.
3. Review your IP address, subnet mask, gateway, DNS, MAC address, and DHCP status.
4. Run the connectivity diagnostics.
5. Use the available diagnostic tools when troubleshooting network problems.

## Important

Only use network scanning, port testing, and other diagnostic features on networks and systems that you own or have explicit permission to test.

Some diagnostic features may require an active Internet connection or appropriate Windows permissions.
